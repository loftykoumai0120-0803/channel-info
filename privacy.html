プライバシーポリシー

本ポリシーは、YouTubeチャンネル「世界の建造物ミステリー」の運営者が使用する動画投稿ツール「yt-auto」(以下「本ツール」)における情報の取り扱いを定めるものです。

1. 利用者

本ツールは、チャンネル運営者本人のみが使用するツールであり、一般の方への提供は行っていません。

2. 取得する情報と利用目的

本ツールは、Google の OAuth 認証を通じて、運営者本人の YouTube アカウントに対する次の権限のみを使用します。

  • 動画のアップロード(youtube.upload):運営者が制作した動画を、運営者自身のチャンネルに投稿するため
  • YouTube アカウントの管理(youtube.force-ssl):投稿した動画のサムネイル設定など、運営者自身の動画を管理するため

これ以外の目的で Google ユーザーデータを利用することはありません。運営者以外の Google アカウントや、視聴者の個人情報を取得することはありません。

3. 情報の保存と第三者提供

認証に必要な情報(リフレッシュトークン等)は、運営者が管理する非公開の環境に暗号化された形で保存され、本ツールの動作以外には使用しません。Google ユーザーデータを販売したり、第三者に提供・共有したりすることはありません。

4. Google API サービスのユーザーデータに関するポリシーの遵守

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に準拠します。

5. アクセス権の取り消し

運営者は、Google アカウントの「サードパーティ製のアプリとサービス」の設定から、いつでも本ツールへのアクセス権を取り消すことができます。

6. 改定

本ポリシーは必要に応じて改定することがあります。改定後の内容は本ページに掲載した時点から適用されます。
