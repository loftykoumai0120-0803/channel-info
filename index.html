世界の建造物ミステリー

「世界の建造物ミステリー」は、世界の橋・塔・ダム・古代遺跡などの建造物の謎や裏側を、建設に詳しい教授と好奇心いっぱいの男の子の掛け合いで、子どもにもわかる言葉で解説するYouTubeチャンネルです。

yt-auto について

yt-auto は、本チャンネルの運営者が、自分のYouTubeチャンネルに動画を投稿するためだけに使用する社内ツールです。YouTube Data API を利用して、運営者自身が制作した動画・タイトル・説明文・サムネイルを、運営者自身のチャンネルにアップロードします。

このツールは一般の方への提供を行っておらず、運営者以外のGoogleアカウントの情報にアクセスすることはありません。
